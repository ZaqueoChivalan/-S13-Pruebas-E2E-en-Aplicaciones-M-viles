S13 / LECTURA TÉCNICA · 5 MINUTOS

Arquitectura pequeña, flujo verificable.

AgendaPro es una aplicación móvil Expo/React Native diseñada para demostrar una prueba de extremo a extremo completa. El diseño mantiene el estado en memoria para que los escenarios sean deterministas y rápidos en un entorno académico.

CAPA UI

React Native

Pantallas y componentes reutilizables con navegación por estado y selectores testID.

RUNTIME

Expo SDK 51

Arranque del proyecto, empaquetado Android y ejecución en emulador.

E2E

Maestro

Flujos YAML legibles que interactúan con elementos visibles y verifican resultados.

Flujo de datos

EntradaRol, nombre, fecha y hora.
→
EstadoselectedProfessional + reservations.
→
SalidaConfirmación o panel profesional.

Patrones y decisiones

State-driven UI

Una pantalla se deriva del estado; cada transición tiene un resultado visible, ideal para E2E.

Componentes puros

Home, Browse, Booking, Confirmation y Dashboard reciben datos y callbacks explícitos.

Page objects ligeros

Los testID actúan como contrato estable entre la UI y Maestro.

Contrato E2E

launchApp → tapOn(client-role) → tapOn(book-1)
→ inputText(client-name-input) → tapOn(confirm-booking)
→ assertVisible("¡Reserva confirmada!")

Librerías: expo, react, react-native, expo-status-bar. Persistencia: estado en memoria para datos demo. Automatización: Maestro + Gherkin.
